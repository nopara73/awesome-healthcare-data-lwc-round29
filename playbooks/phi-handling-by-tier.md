# PHI Handling by Tier

| Tier | Typical posture | Example controls |
|---|---|---|
| open | public, aggregate, synthetic, or de-identified | standard repo hygiene; never commit local downloads unless license allows |
| registration | click-through, account-gated, or training-gated | track user terms and redistribution limits |
| purchase | paid files with license terms | restrict access and preserve invoices/terms |
| dua | governed Limited Data Set or restricted microdata | approved users, encrypted storage, audit logs, destruction plan |
| irb | human-subjects, genomic, or multimodal controlled access | IRB/DAC approvals, enclave/workbench use, consent-group enforcement |
| mixed | family of resources with multiple access paths | document the sub-resource and access route used |
