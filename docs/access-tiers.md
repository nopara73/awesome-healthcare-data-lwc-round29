# Access tiers

| Tier | Meaning | Typical examples |
|---|---|---|
| open | public download, API, or aggregate portal | NPPES, ACS, PLACES, openFDA |
| registration | free account, click-through terms, or training | MIMIC, LOINC, SEER core research data |
| dua | data use agreement / project approval | Medicare claims, T-MSIS, SEER-Medicare |
| irb | IRB/DAC or human-subjects governed access | dbGaP, UK Biobank |
| purchase | paid license or proprietary component | HCUP, CPT, DrugBank commercial use |
| mixed | family of resources with multiple paths | APCDs, ClinVar/OMIM/gnomAD, GBD+DHS |
