# Governance

## Maintainer model

- Category owners review PRs in their domain.
- Schema changes require maintainer approval and migration guidance.
- Dataset entries older than 180 days should be revalidated or marked stale.
- Proprietary or governed data should be described, not redistributed.

## Decision process

Prefer official source documentation, then peer-reviewed methods papers, then reputable institutional implementation notes. When sources conflict, document the conflict in `quality_gotchas`.
